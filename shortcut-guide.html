⏰ iPhone Rain Alarm Shortcut

Get woken up by an alarm when it's raining in your district — using Apple Shortcuts + HKO Open Data

How It Works

This Shortcut calls the HKO real-time rainfall API directly from your iPhone. If rainfall in your district exceeds your threshold, it creates an alarm set to ring 1 minute from now — effectively waking you up with rain info as the alarm label.

No server or third-party app needed. Everything runs locally on your iPhone via Apple Shortcuts + Clock app.

📡 The API

The Shortcut fetches real-time rainfall data from this HKO endpoint:

https://data.weather.gov.hk/weatherAPI/opendata/weather.php?dataType=rhrread&lang=en

This returns JSON with a rainfall.data array. Each entry has:

{ "unit": "mm", "place": "Sha Tin", "max": 2.5, "main": "FALSE" }

place = district name, max = maximum rainfall (mm) in the past hour.

🔧 Build the Shortcut

Open the Shortcuts app and create a new Shortcut. Add each action below in order:

Part 1: Fetch & Parse Rainfall

  1. Add Get Contents of URL
    URL: https://data.weather.gov.hk/weatherAPI/opendata/weather.php?dataType=rhrread&lang=en
    Method: GET
  2. Add Get Dictionary from Input
    (This parses the JSON response into a dictionary)
  3. Add Get Dictionary Value
    Key: rainfall
  4. Add Get Dictionary Value
    Key: data

Part 2: Find Your District

  1. Add Repeat with Each (over the data array)
    Inside the loop:
  2. Add Get Dictionary Value
    Key: place from Repeat Item
  3. Add If — place contains your district name
    (e.g., Sha Tin — see district list below)
  4. Add Get Dictionary Value
    Key: max from Repeat Item
  5. Add Set Variable
    Name: rainfall, Value: the max value
  6. Add End If
  7. Add End Repeat

Part 3: Create Alarm if Raining

  1. Add If — rainfall is greater than your threshold
    (e.g., 0.5 for light rain, 5 for moderate)
  2. Add Date
    Set to Current Date
  3. Add Adjust Date
    Add 1 Minute to Date
  4. Add Create Alarm
    Time: the adjusted date
    Label: 🌧 Rain Alert! [rainfall]mm in [your district]
    (Use the rainfall variable in the label text)
  5. Add End If
Tip: Name your Shortcut something memorable like "Rain Check" so it's easy to find in Automations.

🔁 Automate It (Every 15 Minutes)

To run the check automatically in the background:

  1. Open Shortcuts → Automation tab
  2. Tap + → Time of Day
  3. Set a start time (e.g., 6:00 AM)
  4. Choose Repeat: Every 15 Minutes
    (If not available, set Daily and create multiple automations at 15-min intervals for your key hours, e.g., 6:00, 6:15, 6:30…)
  5. Select Run Immediately (disable "Ask Before Running")
  6. Choose your Rain Check shortcut as the action
Note on iOS limitations: iOS Automations with "Time of Day" may not support 15-minute repeat natively on all versions. Alternative: create separate automations for each time slot you care about (e.g., 6:00, 6:15, 6:30, 6:45, 7:00 AM). This gives you reliable checks during your wake-up window.
Recommended schedule for morning rain checks:
Set automations at 6:00, 6:15, 6:30, 6:45, and 7:00 AM — covering a full hour before most commutes. The alarm rings only if it's actually raining, so false triggers are rare.

🧪 Testing

  1. Open your Shortcut and tap ▶ Play
  2. If it's currently raining in your district, an alarm should appear in the Clock app within seconds
  3. If it's not raining, temporarily change your threshold to 0 to test, then change it back
  4. Check the Clock app — the alarm will show with your rain info as the label

❓ Troubleshooting

Shortcut fails with "no data"

Make sure the API URL is exactly correct. Tap the "Copy" button above and paste it directly. The API is public and doesn't require authentication.

Alarm doesn't ring

Check that your iPhone isn't in Silent mode (the physical switch on the side). Alarms respect the ringer switch on some iOS versions. Also ensure Do Not Disturb allows alarms.

"contains" doesn't match

Try a shorter substring. For example, use "Kwun Tong" instead of "Kwun Tong District". The API returns place names without "District" suffix.

Automation doesn't run

Go to Settings → Shortcuts → Advanced → enable "Allow Running Scripts". Also make sure "Ask Before Running" is off for your automation.
